# Personal Portfolio Website

Welcome to my personal portfolio website! This portfolio showcases my skills, projects, education, and contact information as a recent Information Technology graduate and aspiring Full Stack Developer.

# Live Demo

🔗 **Portfolio:** https://portfolio-website-yd71.vercel.app/

# Features

- Responsive and modern design
- Smooth scrolling navigation
- Fixed navigation bar
- Home, About, Skills, Projects, Education, and Contact sections
- Resume download option
- GitHub and LinkedIn integration
- Built using clean HTML, CSS, and JavaScript

##  Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Git
- GitHub
- VS Code
- Vercel

## 📥 Getting Started

Clone the repository:


git clone https://github.com/roshniguntuka-IT/Portfolio-Website.git


Navigate to the project folder:


cd Portfolio-Website

Open `index.html` in your preferred browser.
